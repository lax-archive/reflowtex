# The lax fork of ReflowTeX

This repository is [lax-archive](https://github.com/lax-archive)'s fork of
[radek-p/reflowtex](https://github.com/radek-p/reflowtex), the LuaTeX
node-list serializer and Python encode pipeline that derive a reflowable
web rendering of a LaTeX paper. The Lax archive (<https://laxarchive.org>)
uses it to build the reflow view shown beside each submitted paper's PDF.

## Branches

- `main` tracks upstream unchanged.
- `lax` is the branch the archive pins: upstream at
  `36f8365eed25ece1db38e0059bcbba3c250802e1` ("Fix MacOS font resolution
  issues.", 2026-07-26) plus the commits below, one per upstream file
  touched. Each commit message records the derivation and carries an
  `SPDX-License-Identifier: AGPL-3.0-or-later` line.

## What the `lax` branch adds

- **Marker capture** (`src/extract/serializer.lua`): the archive's
  `% lax begin <id>` / `% lax end` passage markers reach the serialized
  stream at three sites — in-paragraph whatsits as `marker` nodes,
  shipout-walk whatsits as `marker` stream items (stock code silently
  drops every vertical-mode marker), and the glyphless-resumed-paragraph
  hoist — with `last_flow` transparency so markers never perturb the
  walk's display-spacing logic. Body emission is gated on ink rather than
  glyphs so standalone figures survive.
- **Marker forms in the wire schema** (`src/schema/latex.proto`): a
  `mark` NodeType and a `marker` ItemKind, each with `side`/`n`. Stock
  `encode_pb` dies with `KeyError: 'marker'` on a stream marker.
- **Footnote references** (`src/extract/serializer.lua`,
  `src/schema/latex.proto`): a footnote's insert at its reference point
  becomes a `footnote_ref` node (wire name `fnref`, `n` = the footnote's
  ordinal in encounter order); a vertical-mode insert (`\thanks`, a
  `\footnotetext` between paragraphs) leaves a stand-in whatsit the walk
  emits as a `footnote_ref` stream item; and each footnote paragraph
  carries `footnote = k` (`Paragraph.footnote`). The endnote emission is
  unchanged — a viewer with a margin rail sets footnote k beside its
  reference, the fallback stays endnotes.
- **Heading skips at page tops** (`src/extract/serializer.lua`): a
  heading that opens a page had its `\@startsection` beforeskip
  discarded with the top-of-page furniture and was welded to the
  paragraph before it. laxreflow.sty records the glue TeX left above the
  heading (`\lastskip` as `\@sect`/`\@ssect` begin) in a whatsit
  (user_id 90212) below that glue; the walk restores it when the heading
  — or the paragraph a run-in `\paragraph` opens — is first on a page,
  the same rule as the `\belowdisplayskip` restore.
- **Encode hardening** (`src/encode/encode_pb.py`): prefer a regenerated
  `latex_pb2.py`, fail loudly on unknown enum values, and serialize
  deterministically through `serialize_document()`.
- **Transforms** (`src/encode/transforms.py`): markers survive
  `strip_unsupported_nodes`; every converted picture passes an
  element/attribute-allowlist SVG sanitizer; the dvisvgm invocation is
  injectable per call (`REFLOWTEX_DVISVGM`); a pre-converted `<src>.svg`
  is consumed as-is, still sanitized, and now *without* requiring a PDF
  beside it (a plain `\includegraphics` may be a raster, and only its
  converted SVG is handed over); and the sanitizer admits an `image`
  element whose `href`/`xlink:href` is an inline `data:` PNG or JPEG whose
  decoded bytes carry the matching magic number — every other reference,
  `data:image/svg+xml` included, still goes.
- **Map-aware, injectable Type1 lookup** (`src/encode/t1_convert.py`):
  `find_outline` resolves a legacy face the way the engines do, through
  its `pdftex.map` line — outline plus, for a re-encoded face, the
  encoding vector (`ec-lmr10` is `lmr10.pfb` through `lm-ec.enc`; stock
  looks for `ec-lmr10.pfb` and finds nothing), and the conversion
  addresses slots by that vector; the f-ligature presentation forms count
  as searchable. With `REFLOWTEX_PFB_DIR` set, `<name>.pfb` and an
  optional `<name>.enc` in that directory are the only source; without
  it, kpsewhich as stock, and a host without kpsewhich yields the
  metric-box fallback instead of a crash. `fonts.provision` skips the
  serializer's `unknown` placeholder and survives a missing kpsewhich.
- **No run-time writes into the checkout** (`src/encode/pipeline.py`):
  `_ensure_pb2` only verifies; `latex_pb2.py` is regenerated by the
  consumer at fetch time into `build/`, never into the vendored tree.

## How the archive consumes it

The `lax` repository (<https://github.com/lax-archive/lax>) pins this
repository and a revision in `src/submission-validation/pins.ts`
(`REFLOWTEX_URL` / `REFLOWTEX_REV`); `npm run reflowtex:fetch` there
clones exactly that revision, installs a hash-pinned Python environment,
regenerates `build/latex_pb2.py` from `src/schema/latex.proto`, and
verifies both marker forms are present. The fetched checkout never enters
the archive's npm package. The browser viewer (`latex-viewer.js`) is
vendored unminified, with this license, by the archive's website.
